操作のヘルプ
タイムライン
タップブロックを選ぶ（Shift/⌘+タップで追加・解除）。空欄ならトラックを選ぶ
ブロックの上からドラッグなぞったブロックをまとめて選ぶ
長押し → ドラッグ選んだブロックを移動（後ろは押し出し）
ダブルタップ → ドラッグ選んだブロックを複製して置く
掴んだまま上へ弾く移動中なら削除、複製中なら取り消し
ダブルタップ空欄: 空のブロックを追加（コード名の入力は、下のブロック編集で名前をダブルタップ、または Tab）
空欄でダブルタップ → 長押しリピートを追加
右端をドラッグ長さを変える（グリッドに吸着）
2本指で横にスワイプタイムラインをスクロール
2本指で長押し → 横にドラッグ時間方向の拡大（右）・縮小（左）。左端の位置は動かない（方法は設定で切り替え）
キーボード（⌘ = Cmd / Ctrl、⌥ = Option / Alt）
Space / ,再生・停止 / 先頭へ
← → ↑ ↓ブロックを選ぶ（↑↓で隣のトラックの同じ位置へ）。何も選んでいなければ1つ目
⌘← / ⌘→選んだブロックをグリッド1つ分動かす（隣と接していれば入れ替え）
⌥← / ⌥→選んだブロックをグリッド1つ分短く / 長く
Shift+← / Shift+→選択を広げる / 狭める（同じトラック内）
b / r / dブロックを追加 / リピートを追加 / 直後に複製
g / h時間方向に縮小 / 拡大（左端は固定）
Delete選んだブロックを削除（確認なし。⌘Zで戻せる）
1〜5 / 6グリッド 1/1・1/2・1/4・1/8・1/16 / 3連に切り替え
Tab / Shift+Tabコード名を入力して次 / 前のコードへ（リズムはステップのキーボード編集）
⌘Z / ⇧⌘Z元に戻す / やり直す（Ctrl+Z / Ctrl+Y）
ステップ（リズムブロック）
ダブルタップ打ち込み・消去（右クリックで強弱）
タップ / ドラッグマスを選ぶ / 四角く選ぶ（休符のマスも選べる）
長押し → ドラッグ選んだマスを移動（掴んだまま上へ弾くと消去）
ダブルタップ → ドラッグ選んだマスを複製
2本指で横にスワイプステップをスクロール
ステップのキーボード編集（リズムブロックを選んで Tab で開始。編集中はマスのダブルタップでカーソルを移動）
← → ↑ ↓カーソル（マス）を動かす。Shift+矢印で範囲を選ぶ
q / w / e弱・中・強で打ち込んで、次のマスへ
Shift+q / w / e選んだマスから右端まで全部打ち込む
Shift+d選んだマスを右端まで繰り返し複製して埋める
Shift+Backspace選んだマスの行（その楽器の横一列）を消す
⌥+Backspace選んだマスの縦一列（その位置の全楽器）を消す
Shift+⌥+Backspaceブロックの中を全部消す
Backspace選んだマスを消す
⌘+矢印選んだマスを移動
d選んだマスを右隣に複製
⌥← / ⌥→ブロックを短く / 長く
Tab / Shift+Tab次 / 前のリズムブロックへ
Enter / Esc終了
